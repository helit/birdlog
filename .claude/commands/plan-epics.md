# /plan-epics — Stage 2: Epic planning

```
Skill({skill: "plan-epics"})
```

Reads `docs/PRD.md` and facilitates a sprint-planning session that breaks the product into 3–8 prioritised epics. Creates or updates parent issues in the issue tracker (one per epic, labelled `epic`).

**Run when:** after `/define-prd`, or whenever you need to re-prioritise the roadmap.

**Next:** `/define <epic#>` to start the first feature in a Wave 1 epic.
